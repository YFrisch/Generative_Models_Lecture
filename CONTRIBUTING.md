# Contributing

Feedback and contributions are welcome. Useful contributions include corrections to explanations or mathematics, clearer visualizations, bug fixes, and improvements to notebook reproducibility or accessibility.

Before submitting a pull request:

1. Create a focused branch and keep the change limited in scope.
2. Run the affected notebook from a clean kernel, or explain why a full run is impractical.
3. Run the inexpensive structural checks documented in the README.
4. Describe what changed, why it is useful, and any runtime or checkpoint implications.

For substantial changes, open an issue first so the proposed direction can be discussed before implementation.
